# 地籍圖調整工作台（第三版）

**使用**：雙擊 `index.html`（Chrome / Edge），不用安裝。把案件資料夾拖進視窗。核心功能離線可用；底圖需連網。

## 資料輸入
- 圖資：`D14`+`D13`（建議加 `D11`、`D12`；同資料夾的 `D2C`+`D2B` 當舊圖疊示），或 `COA`+`BNP`（+`PAR`）
- 控制點／補點（已知點庫）：`CTL`、`CT2`、`CEN`、`L02`，或案件的 `D20`——可在圖資之前或之後匯入
- 現況點：「匯入現況點」→ ① `點號,N,E` 的 CSV/TXT ② **MAC 手簿檔** ③ 測站角度距離（自填測站）
- **MAC 是相對觀測，必須先匯入控制點／補點**；程式依「測站 後視」逐段化算，新測站可供後續段落使用，並顯示後視距離檢核差；缺少已知點會明確列出

## 編輯
- 選取：「點／線／面」可複選；Shift 加選；框選。拖曳、方向鍵、ΔN/ΔE 移動；共用界址點使鄰地一起變動，面積與較差即時顯示（表格＋圖上標示）
- 移圖（M）：整張新圖平移；Shift+拖曳旋轉；輸入角度按 ↺／↻（可 `0-30-00`）；Alt+點擊自訂樞紐
- 兩點對位：新圖 A → 目標 A′ → 新圖 B → 目標 B′，自動算旋轉與平移（不縮放，回報距離比）
- 連線（L）：依序點現況點連成參考線；點回第一點閉合並顯示面積／周長

## 底圖與列印
- 底圖：OpenStreetMap／國土測繪中心 電子地圖／正射影像（需連網；僅適用 TWD97；澎金馬選 119°E）
- 列印（Ctrl+P）：A4/A3、橫直式、比例尺 1:200～1:5000 或自動、範圍（畫面／全圖／選取或有變動），附標題欄、圖例、比例尺條、指北；選「另存為 PDF」輸出 PDF；亦可輸出 PNG

## 輸出
- 輸出 D14：只改被移動點的坐標，其餘位元組與原檔相同。**覆蓋案件資料夾前請先備份**。D11 面積欄位不改，請在 NECEXE 內「重算面積」
- 輸出 JSON：移動點、面積變化、控制點、現況點、參考線
- AI 介面：`window.CadastralAPI`（getState / select / transform / alignTwoPoints / importControls / importMac / importSurveyPoints / addLine / listLines / setBasemap / getView / exportSession …）；網址加 `?bridge=ws://127.0.0.1:埠號` 可接 WebSocket（預留 MCP）

## 驗證
`samples/kc0381`（1293 宗）、`samples/KC1119`（1018 宗，含弧線與地中地）的面積皆與 NECEXE 的 D11 吻合；TWD97 轉換以數值積分獨立檢驗。
**開發**：原始碼在 `../src/`，`node ../build.mjs` 重建，`node ../test/core.test.mjs` 跑測試。
**尚未做／尚未驗證**：輸出 DXF 與舊圖(D2x)、D11 面積回寫、輸出的 D14 實際匯入 NECEXE、實體印表機列印、MAC 距離為斜距時（目前視為平距）。
